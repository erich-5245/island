常見問題

你可能想問。

會不會拖慢電腦？

幾乎不會。隱藏時 CPU 大約 0.05%（單核），記憶體約 20–45 MB。它不會一直在背景檢查東西，而是等系統通知「有事發生了」才動作。

會不會上傳我的資料？

不會。Island 沒有帳號，也不收集任何使用資料。只有兩個功能會連網：天氣（向 Open-Meteo 查詢，只送出你選的城市座標）和行事曆（只讀取你自己貼上的 iCal 網址）。不用這兩個功能，它就完全不連網。程式碼都公開在 GitHub 上，可以自己檢查。

看影片、玩遊戲時會跑出來擋畫面嗎？

不會。島所在的螢幕上有全螢幕程式時（影片、遊戲、簡報、瀏覽器按 F11），它會自動隱藏，離開全螢幕就回來。這個行為也可以在右鍵選單裡關掉。

我有兩個以上的螢幕，可以用嗎？

可以。島預設跟著 Windows 的主螢幕，也可以在設定裡指定要顯示在哪一個螢幕。視窗切換會列出所有螢幕上的視窗；不同縮放比例的螢幕也會正確對齊。

設定和資料存在哪裡？

全部存在 %LOCALAPPDATA%\Island，只屬於目前的使用者。設定也可以在設定視窗裡匯出成檔案，帶到另一台電腦匯入。

要怎麼關掉或解除安裝？

想暫時關掉：在島上按右鍵 →「結束」。想解除安裝：Windows 設定 →「應用程式」→ 找到 Island → 解除安裝。解除安裝時會順便移除開機啟動，並先問你要不要一起刪掉設定資料。

第一次執行時看到「Windows 已保護您的電腦」？

Island 的安裝程式目前沒有數位簽章，所以 SmartScreen 會攔一下。按「其他資訊」→「仍要執行」即可。想確認檔案沒被改過，可以用 Releases 頁面上的 .sha256 核對。
